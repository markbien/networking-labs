# Networking Labs

A collection of my hands-on networking labs completed while studying networking fundamentals and preparing for the Cisco CCNA 200-301 certification.

This repository documents my practical exercises using Cisco Packet Tracer, including network topologies, device configurations, troubleshooting, and key takeaways.

## Objectives
- Develop practical networking and troubleshooting skills.
- Apply networking concepts through hands-on labs.
- Document configurations, issues encountered, and solutions.
- Track my progress toward the CCNA 200-301 certification.
